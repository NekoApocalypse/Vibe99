# Vibe99：图片粘贴与首次点击激活

Review 9 让 Windows 用户把截图直接粘贴到 Codex / Antigravity CLI（agy）输入框，包括 SSH 主机上的 tmux。复制图片后按 Ctrl+V、Ctrl+Shift+V 或右键 Paste Image：Vibe99 保存 PNG，必要时上传，再粘贴工具能访问的路径；工具识别为附件，**不会自动提交提示词**。同时，非活动 pane 的第一次点击只激活它，第二次才打开 URL、Markdown 路径或操作文档。

支持剪贴板位图；Explorer 复制文件不在本次范围。自动远端定位限于 Windows pane 中可识别的直接 SSH，目标需已有免交互认证、已信任主机密钥和 Linux Python 3。复杂连接会询问目标；嵌套 SSH、WSL 和容器的真实文件系统不会自动解析。其他不识别图片路径的程序会收到普通路径文本。

实现沿用现有终端粘贴和 SSH 上下文能力：`src/clipboard-paste.js` 统一入口，`src-tauri/src/clipboard_image.rs` 在线程池处理 PNG 和一次性 SSH 上传，`remote/store_clipboard_image.py` 落盘后退出。无需远端常驻服务，也不向现有 tmux 会话注入上传命令。失败、终端更换、返回本地提示符或完成时焦点已离开源 pane，均不插入路径；错误显示在界面。人工目标上传成功后才记住。

图片上限为 32 Mi 像素、16 MiB PNG。本地保存在应用缓存，远端保存在临时目录的用户专属子目录（目录 0700、文件 0600）。关闭 pane、退出应用或分离 tmux 不立即删除图片；后续粘贴会清理超过七天的文件，系统临时目录清理也可能更早删除。长期对话请另存原图。pane 的排序、宽度及前景不透明／背景透明关系保持原样。
