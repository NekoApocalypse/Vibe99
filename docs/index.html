Vibe99

Download Latest Release (v0.7.3) View on GitHub

One developer now runs four or five coding agents at once. Traditional terminals give you two bad choices: tabs hide background agents until you forget they finished, while split grids shrink every pane until you cannot read any of them.

Vibe99 is a desktop terminal workspace built for one focused pane, peripheral vision on the rest. You read and command one agent at full width, while the others stay stacked on screen so you can see every session move at a glance.

一个人同时跑四五个 Coding Agent 已经是常态。但传统终端只有两种糟糕的选择：切标签页会把后台 Agent 彻底藏起来，跑完了也忘看；十字分屏又把每个窗口挤成豆腐块，哪一个都看不清。

所以我做了 Vibe99——一个按 「一主聚焦、余光巡视」 设计的 Agent 终端工作台。当前操作的终端永远保持全宽可读，其余终端层叠在侧，所有 Agent 的动静尽收眼底。

  • Focus-first stacked layout. Keep your active terminal wide and readable (1210 px default) while background panes stay partially visible in the stack. You never lose sight of running agents.
  • Instant keyboard switching. Cycle recent panes with Ctrl+Tab, step left or right with Ctrl+Left and Ctrl+Right, fuzzy-search tabs via the command palette (Ctrl+Shift+O), or enter Vim-style navigation mode (Ctrl+B, then H/L or 1–9).
  • Distinct pane colors and breathing alerts. Every pane gets an Okabe-Ito high-contrast color so you can tell agents apart at a glance. When a background agent finishes output and settles, its mask can pulse softly until you check it.
  • Built for daily shell hazards. Recover mouse input after a dropped SSH session with Ctrl+Shift+M without losing scrollback. Render CJK characters at full two-cell width so Claude Code and TUI redraws never drift. Discover Windows WSL distributions in the background without slowing down startup.
  • Native Tauri 2 + Rust speed. Built on Tauri 2, portable-pty, and WebGL-rendered xterm.js. Installs from a ~5 MiB native package and restores your pane layout, working directories, shell profiles, and tab titles on restart.

Getting started

  1. Download a release. Windows (.msi, -setup.exe) and Linux (.deb, .AppImage, .rpm) installers are published on GitHub Releases.
  2. Preferred for source builds: let your agent do it. Copy https://github.com/NekoApocalypse/Vibe99 into your coding agent (Claude Code, Codex, Antigravity, or OpenCode) and ask it to build and launch Vibe99.
  3. Build it yourself. Requires Node.js 22+ and a stable Rust toolchain. 
    npm ci
npm run tauri:dev
    To package native release installers for your platform: 
    npm run tauri:build

Controls

ShortcutAction
Ctrl+N (Cmd+N on macOS)Open a new terminal pane
Ctrl+Tab / Ctrl+Shift+TabCycle through recently visited panes
Ctrl+Left / Ctrl+RightMove focus to the adjacent pane on the left or right
Ctrl+Shift+O (Cmd+Shift+O)Open the command palette and jump to any pane by title
Ctrl+BEnter navigation mode (H/L or arrows to move, 1–9 to jump, N new, R rename, X close, Enter focus)
Ctrl+Shift+C / Ctrl+Shift+VCopy or paste in the focused terminal
Ctrl+Shift+MRecover mouse input after an interrupted SSH or TUI session

Double-click any tab to rename it, drag tabs to reorder panes, or right-click a tab to switch its shell profile, color, or activity alert. All shortcuts can be customized under Settings → Keyboard Shortcuts.

Limitations

  • Release platforms: Prebuilt installers target Windows (x64) and Linux (x86_64). macOS users can build and run from source (npm run tauri:build), as prebuilt macOS artifacts are paused until Apple signing and notarization are worth the cost.
  • Windows code signing: SignPath Foundation onboarding is in progress (Code signing policy). Releases up to v0.7.3 are unsigned and may show a Windows SmartScreen prompt on first launch.
  • Out of scope: Code editors, file trees, Git GUIs, and remote agent daemons. Vibe99 is a fast, focused terminal workspace for running and supervising agents—pair it with Owlet when you want a fast reader and editor for the files your agents produce.

Vibe99 — 多 Agent 终端工作台

  • 一主聚焦、余光巡视的层叠布局：当前交互的终端保持大宽度清晰显示（默认 1210 px），后台终端层叠排布在视野边缘，随时看清每个 Agent 是在跑任务还是在等指令。
  • 全键盘瞬时切换：支持 Ctrl+Tab 按最近访问顺序切换、Ctrl+Left / Ctrl+Right 按空间位置平移、Ctrl+Shift+O 呼出命令面板模糊搜索标签页，或按 Ctrl+B 进入导航模式（H/L 移动、数字键 1–9 直达）。
  • 高对比主题色与呼吸灯提醒：内置 Okabe-Ito 高辨识度调色盘，靠颜色一眼区分不同窗口的 Agent；后台终端输出完毕静止后，可开启呼吸灯柔光提醒，切回即停。
  • 专为真实终端痛点打磨：SSH 断连后鼠标滚轮乱码可按 Ctrl+Shift+M 一键恢复且保留滚屏历史；精准对齐中日韩（CJK）双宽字符，跑 Claude Code 等 CLI 绝不发生输入漂移；后台异步探测 Windows WSL 发行版，绝不拖慢冷启动。
  • Tauri 2 + Rust 原生轻量体验：告别臃肿的 Electron，基于 Tauri 2、portable-pty 与 WebGL 加速的 xterm.js 重构，原生安装包仅 ~5 MiB，重启自动恢复窗口布局、工作目录、Shell 配置与标签页标题。

快速开始

  1. 直接下载安装包。 前往 GitHub Releases 下载 Windows（.msi、-setup.exe）或 Linux（.deb、.AppImage、.rpm）安装包。
  2. 从源码构建（推荐交给你的 Agent）。 把仓库地址 https://github.com/NekoApocalypse/Vibe99 丢给你常用的 Coding Agent（Claude Code、Codex、Antigravity、OpenCode 等），让它直接构建并启动 Vibe99。
  3. 手动构建。 环境要求：Node.js 22+ · Rust stable 工具链。 
    npm ci
npm run tauri:dev
    打包当前平台的原生安装包： 
    npm run tauri:build

当前局限

  • 平台安装包：目前提供 Windows (x64) 与 Linux (x86_64) 预编译安装包。macOS 预编译包在 Apple 签名与公证成本划算前暂停发布，macOS 用户可直接从源码构建运行（npm run tauri:build）。
  • Windows 代码签名：正在接入 SignPath Foundation 开源签名（详见 Code Signing Policy）。v0.7.3 及更早版本的 Windows 安装包尚未签名，首次运行可能触发系统 SmartScreen 提示。
  • 不做的功能：内置代码编辑器、文件树、Git 图形界面或远端常驻守护进程。Vibe99 专注于让你高效并行操控多个终端 Agent——如果你需要极速审阅和编辑 Agent 产出的文档与代码，推荐配合 Owlet 一起使用。
